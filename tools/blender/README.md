# Blender sources for AFTERHOURS models

The models in `models/` are generated by these scripts. Run them with Blender's Python (`bpy`) and they rebuild the exact GLB the game loads.

| Script | Output | Run |
| --- | --- | --- |
| `volcano_p1.py` | `models/volcano_p1.glb` (Volcano P1 body) | `python3 volcano_p1.py --out ../../models/volcano_p1.glb [--render preview]` |
| `autobahn_63.py` | `models/autobahn_63.glb` (AUTOBAHN 63 v2 body) | `blender -b -P autobahn_63.py -- --out ../../models/autobahn_63.glb`, or live over MCP: exec it, `dump_mesh.dump(ns['objs'])`, then `python3 pack_glb.py dump.json ../../models/autobahn_63.glb` |
| `philly_kit.py` | `models/philly_kit.glb` (City Hall, Art Museum, Boathouse Row A-D, BFB tower) | live over MCP: exec it, `dump_kit.dump(roots)`, then `python3 pack_glb.py --kit dump.json ../../models/philly_kit.glb`. Headless works too with the `bpy` pip module: exec it, dump the parents of `objs` the same way, then pack |
| `kage_r.py` | `models/kage_r.glb` (Kage R body) | exec `carlib.py` then this file in one namespace (live over MCP, or headless with the `bpy` pip module), `dump_mesh.dump(ns['objs'])`, then `python3 pack_glb.py dump.json ../../models/kage_r.glb` |
| `preview_rig.py` | studio renders (not exported) | exec after a build, then `shots([...])` |
| `blvd_kit.py` | `models/blvd_kit.glb` (Roosevelt Blvd streetlight, guardrail, trees, guide sign) | `python3 blvd_kit.py --out ../../models/blvd_kit.glb [--render preview]` |
| `mtairy_kit.py` | `models/mtairy_kit.glb` (Germantown Ave shops, Art Deco theatre, stone twin) | `python3 mtairy_kit.py --out ../../models/mtairy_kit.glb [--render preview]` |

Coordinates are authored in game space (x right, y up, z forward) and mapped to Blender with `G(x, y, z) = (x, -z, y)`, so the glTF Y-up export lands back in game space. Material names (`PAINT`, `CARBON`, `GALV`, `SIGN`, …) are the contract with `js/afterhours.js`, which swaps them for the game's own materials.

Detail policy: kit boxes and prisms go through a `bmesh.ops.bevel` pass (the `volcano_p1.py` call) so corners catch the night rig's highlights, and round parts use the higher segment counts in each script (`SEG_DETAIL` in `philly_kit.py`). After a rebuild, bump the kit's `?v=` in the `GLTFLoader` `want` list in `js/afterhours.js`.
