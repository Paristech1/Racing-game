# Agent skills attribution

## Three.js (this game)

The `threejs-*` skill directories and `afterhours-threejs` are copied from [CloudAI-X/threejs-skills](https://github.com/CloudAI-X/threejs-skills) (MIT License). They document Three.js r160+ module APIs; see `afterhours-threejs/SKILL.md` for how this repo uses r128 script tags instead.

## NVIDIA SkillSpector

`skill-inspector/` is from [NVIDIA/SkillSpector](https://github.com/NVIDIA/SkillSpector) (Apache-2.0). Use it to review third-party skills before install; run the `skillspector` CLI when available.

## Waza

`think`, `ui`, `check`, `hunt`, `write`, `learn`, `read`, and `health/` are from [tw93/Waza](https://github.com/tw93/Waza) (MIT). Generic engineering habits (planning, UI, review, debug, prose, research, fetch, agent health). Installed from `skills/` only (not the duplicate `plugins/waza/skills/` tree).

## Anthropic Cybersecurity Skills

818 skills under kebab-case directory names (e.g. `triaging-security-incident/`) are from [mukul975/Anthropic-Cybersecurity-Skills](https://github.com/mukul975/Anthropic-Cybersecurity-Skills) (Apache-2.0). Community project, not affiliated with Anthropic PBC. **Authorized security work only** — see upstream `SECURITY.md`. Discovery index: `cybersecurity-index.json` in this folder.
